GTFO Model Catalog

Every mesh and every top-level object (a prefab or scene root) in the game's data files, read offline. Sizes are the mesh's bounding box in metres. To borrow a model in a mod you still need its load path (like Assets/AssetPrefabs/Items/Consumables/LockMelter/...prefab), which only the running game lists.

Regenerate after a game update with tools/model-catalog in GTFO.EZ, which also writes this list to reference/gtfo-models.csv, committed in the repo (it never goes in the mod's download). Names with a g_ prefix are usually the visible mesh, c_ its collision and d_ a decal or damage variant.
